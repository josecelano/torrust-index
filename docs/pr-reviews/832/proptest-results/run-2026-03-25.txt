2. P2 (range_sum_additivity):
   Initial version asserted exact equality:
     range_sum(lo..m) + range_sum(m..hi) == range_sum(lo..hi)
   Minimal failing input:
     ops = [Observe{coord:0, delta:3}, Observe{coord:0, delta:60},
            Observe{coord:0, delta:1}]
     lo=0, m=1, hi=5
     range_sum(0..1)=0, range_sum(1..5)=0, range_sum(0..5)=1
   Root cause: range_sum uses f64 pro-rating for nodes where the query
   boundary bisects the node's spatial range.  Independent floor()
   truncation on each sub-query means additivity only holds exactly when
   all boundaries coincide with G-node edges.  This is documented in the
   range_sum docstring ("pro-rated partial overlaps", ADR-M-020).
   Fix: loosened assertion to allow |combined - total| <= N = 8.
